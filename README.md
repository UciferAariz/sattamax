# GameCredits Casino — Mines + Plinko

A Stake-style, **credits-only** casino built with **React + Vite + Tailwind** and ready for **Netlify**.

## Local dev
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy (Netlify)
- Connect this repo to Netlify.
- Build command: `npm run build`
- Publish directory: `dist`
- Or keep the provided `netlify.toml`.
